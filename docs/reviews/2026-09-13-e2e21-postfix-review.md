## 1. 产品代码轨

### A1（**第一优先**）| 中（若把该清单当验收面则高）| `meeting_fs.py:286,288,290,292`（+`:195-196`、`docs/design.md:416-418`、`tests/test_meeting_fs.py:1164-1175`）

**问题**：`af_resolution_notes` 的 5 组路径里 **4 组 legacy 路径整体多一层 `aft/`** ⇒ 全部是死检查（永远命中不了真实文件）。

**依据**（上游源码，`@cortexkit/aft-pi@0.55.1` 与 `@cortexkit/aft-bridge` 的 paths 模块逐字一致；**三方各自独立核实**）：

```js
function legacySources(basePath, …) { return [ {path: `${basePath}.jsonc`}, {path: `${basePath}.json`} ]; }  // 追加后缀，不进目录
user:    legacySources(join(legacyOpenCodeConfigDir(), "aft"))      // → <configHome>/opencode/aft.jsonc
         legacySources(join(legacyPiAgentDir(),        "aft"))      // → ~/.pi/agent/aft.jsonc
project: legacySources(join(projectDir, ".opencode",   "aft"))      // → <proj>/.opencode/aft.jsonc
         legacySources(join(projectDir, ".pi",         "aft"))      // → <proj>/.pi/aft.jsonc
```

第 5 组（`<proj>/.cortexkit/aft.jsonc`）**正确**（上游 `resolveCortexKitProjectConfigPath`，只读 `.jsonc`）。

**后果**：用户若有 legacy 配置（如 `~/.pi/agent/aft.jsonc`），AFT 的 `markLegacySourcesMovedAside` 会
**无条件 `unlinkSync`** 该文件（原文留在 `<名>.MOVED_READPLEASE`），而这行"提示事实"的输出不会触发
——即 `design.md` 决策 19 承诺的**可见性没有兑现**（职责边界：副作用是我们注入 `XDG_CONFIG_HOME` 引入的）。

**修法（共识，性能/简单/铁律一致）**：
- **与上游同形**：4 个 base（`join(root, "aft")`）+ 一条 `base + ".json[c]"` 后缀规则，替代 8 个手抄字符串
  ⇒ "多一层 `aft/`"这类翻译错误**结构上不可能再发生**；
- `OPENCODE_CONFIG_DIR` **收回归根解析**（上游 `legacyOpenCodeConfigDir()` 的分支），清单里不再有特例；
- 第 5 组**保持独立一行 + 独立 note**（属另一上游函数：生效的目标配置 ≠ legacy 源）；
- **护栏**：检测只做 `os.path.isfile`，**不读文件内容**（"会不会被删"由上游决定，不复制其判定链）；
- 同步 `meeting_fs.py` docstring、`docs/design.md:416-418`、**测试期望路径**（现测试写的正是错误嵌套形态 ⇒ 同源自证）。

**判据（机械可核查）**：
1. **正例**：造 flat 形态（`<home>/.pi/agent/aft.json`、`<proj>/.opencode/aft.jsonc`）→ 断言报告路径集合**包含**它们；
2. **负例（独立成条）**：只造 nested 形态（`<root>/aft/aft.json[c]`）→ 断言 `out == []`；
3. 旧实现上**双向变红**（正例不命中、负例反而命中）⇒ **判别力型**；
4. 测试注释引上游用**函数名**（`join(legacyPiAgentDir(),"aft") + ".json[c]"`），**不用**会话编号/行号（#17）；
5. 不得用 `len(out) == N` 当唯一判据（数目巧合型弱断言）。

## 2. 测试轨

### P1 | 判别力型（对 F1）| `tests/test_main_paths.py`（扩既有 `_env` fixture）

**断言**：① 报告 `sec` 合计 == 仅本轮（历史不计入）；② **`ΣΔ ≤ 进程跨度`**。

### S-2 / S-6 单点断言 | 判别力型（各对其修复）| `tests/test_meeting_fs.py`

**规格（原写法不可实施，已作废重做）**：`build_agent_config` 源码实测含
`"cortexkit"`×2（`:52` 源侧目录、`:53` 目标侧目录）与 `"aft.jsonc"`×1（`:59` 源侧文件）

目标侧由 S-2 的 `agent_config_cortexkit_dir` 覆盖 ⇒ 不变式成立且可绿（**≈ +2 个推导**）。
